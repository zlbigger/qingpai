# 轻排 · 公众号排版插件

按 zlbigger 的个人使用习惯制作，未必适合每个人的需求。

个人主页：https://zlbigger.com/
源码、完整文档与问题反馈：https://github.com/zlbigger/qingpai
网页版：https://lab.ideafactorys.com/qingpai/

## 安装与更新

在 Chrome 的 chrome://extensions/ 开启开发者模式，加载本目录（包含 manifest.json）。更新文件后点击重新加载，再刷新公众号编辑页。

## 使用

整篇排版在公众号原生工具栏下方，点击风格立即生效。基础文字编辑使用公众号自己的工具栏。

在公众号图库里，“默认”逐张插入；主动选择 2、3、4、6、9 图布局后，选齐相应数量并点确定即可拼排。点击正文图片组，在左侧调整顺序、间距、圆角或整组换图。

本插件不会发表文章，不上传图片到第三方。兼容性依赖公众号当前的编辑器及图库实现，请先在测试草稿中试用，并使用公众号手机预览确认效果。MIT 许可。
